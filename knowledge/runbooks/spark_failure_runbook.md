# Spark Failure Runbook

Inspect structured failure evidence, Spark job/stage/task behavior, shuffle and resource symptoms, then separate infrastructure/transient failure from data-contract failure. Do not classify a failure solely from free-text logs when structured failure tags are unavailable.
